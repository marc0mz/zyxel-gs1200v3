# Contributing

Issues and pull requests are welcome. The maintainer reviews and decides which changes to accept.

## Issues

- Use an issue to report a bug or suggest a change.
- Include the Home Assistant version, integration version, switch model and firmware, and steps to reproduce.
- Remove passwords, access tokens, public IP addresses, and other private information from logs and screenshots.

## Pull requests

- Open a pull request against `main` and describe what changed and why.
- Include the Home Assistant and switch versions used for validation, where relevant.
- Run the repository's HACS and Hassfest GitHub Actions and address any failures.
- Do not include credentials, private logs, or unrelated files.

By submitting a contribution, you agree that it may be distributed under this repository's MIT License.
